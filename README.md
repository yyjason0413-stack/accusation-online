# 控訴 Online（v1：白狐神社／鴉教團）

手機優先的《控訴》線上 1 對 1 對戰。Node 權威伺服器保存完整遊戲狀態，手牌與牌庫不會傳給對手的瀏覽器。

## 執行
```
npm install
npm start            # http://localhost:8787 （PORT 環境變數可改）
./start.sh           # 背景常駐（當掉會自動重啟）
npm test             # 61 個規則／卡片單元測試 + 隨機機器人整局模擬
npm run e2e          # Playwright 兩支手機連線整局測試
```

## 結構
- `engine/engine.js`：規則引擎（回合、行動、襲擊、災厄／控訴、星塵、駐守、儀式、勝負）
- `engine/effects.js`：48 張卡的效果
- `engine/bots.js`：隨機機器人（測試用）與簡易 AI（單人練習）
- `server.js`：HTTP + WebSocket（並附 HTTP 長輪詢備援）、房號、斷線重連、AI 房
- `public/`：手機網頁前端（純 JS），`public/img/` 為卡圖
- `test/`：單元測試、模擬、端對端測試

## 裁定（需原作者確認）見回報內容。

### 主要裁定摘要（2026-11-12 原作者確認後）
- 只有魔法被控訴時置入棄牌區；被控訴的信徒、地點、儀式、教主留在場上，只是效果／詠頌不結算（被控訴的信徒也不能駐守）。
- 教主需任一方計分區已有至少 1 個儀式後，才能從陰謀區打出（1 行動）。
- 駐守可疊加：多個信徒可駐守同一地點，守護相加。
- 《巢修道院》只計算它上場之後的第一次詠頌。
- 《失眠掘墓人》不會觸發拿回手的信徒的詠頌。
- 組牌：教主＋固定 3 張儀式，另 20 張中至少 12 張與教主同教團，其餘至多 8 張來自另一個教團（限 1 個）與任意張放逐者；20 張全用主教團亦合法；每張限 1 張。
- 逐光者（2026-11-12 起全自動）：《回歸原始》「遊戲開始時」＝雙方調度結束後、第一回合前；《寄生的信者》改變地點類型，《沼澤女巫》因此移出；《漆黑樹洞》免費襲擊含聖戰、行動用完也能用；「你每擁有…」次數在結算時固定並逐次選擇。
- 禁忌廚房（2026-11-12 起全自動）：供品被破壞時效果先結算，再繼續原效果；《食材輸送帶》在被破壞時效果之後才把信徒移入陰謀區；《冷藏櫃》執行時效果不受控訴影響；《主廚》只在敵方回合結束時把手牌上限改為 5。
- 同時觸發：「時」類先於「後」類（例如食材輸送帶）；同類有多個不同效果時由回合玩家選擇順序；結算中新產生的觸發先結算。
- 門教團（2026-11-12 起全自動）：《增幅管道》免費魔法行動用完也能打；從牌庫頂獻祭要先選儀式才能看；《知罪者》用來控訴（變罪惡）也會觸發。
- 瘋人院（2026-11-12 起全自動）：控制權——被控制的牌放在控制者場上、視為控制者的卡；離場時進入控制者的對應區域（設計者 2026-11-13 裁定：控制權轉移後完全成為控制者的牌）；由附著魔法（《深度催眠》《原始樣本-寄生》）給予的控制權，在魔法離場而該牌仍在場上時歸還原持有者（遊戲開始時擁有該卡的玩家）。附著的魔法回打出者棄牌區。失去效果欄能力的信徒也失去聖戰／供品／只能單獨襲擊／不會變罪惡等能力。
- 疫病中心（2026-11-12 起全自動）：聲量增減只作用於場上信徒，可降到負數（襲擊時以 0 計；控訴聲量不受影響）；《原始樣本-寄生》讓信徒暫時成為持有者的地點「荒野」（守護＝卡面聲量，保留符號），魔法離場即恢復為罪惡信徒；附著魔法＝效果欄以「附著」開頭的魔法；《進化樣本-鼠王》勝利＝立即獲勝。
- 紫靈山（2026-11-12 起全自動）：飛升（設計者 2026-11-19 裁定）＝只能用回合行動以飛升方式打出（不能控訴、不能被任何效果放置到場上）；打出前除外你場上非教主牌直到滿足需求，每張牌只提供 1 個符號（剛好除外所需張數）；《著魔煉丹師》可當任意 1 個符號；飛升需求減少直接減少要除外的張數；觸發魔法基礎效果不算打出、不能被控訴、不啟動星塵效果；《蠱祖降臨》勝利＝立即獲勝。
- 《疫苗研製》：自己場上所有牌（含教主、儀式、罪惡信徒、取得控制權的牌）卡面下方圓形符號合計 6 種即可。
- 預設牌組：疫病中心改為 14 張主教團＋白狐神社／放逐者 6 張（讓《疫苗研製》的 6 種符號可達成）。
- 設計者裁定（2026-11-13）：魔法的基本效果與星塵效果互相獨立，基本效果無法結算時星塵效果照常結算；比較「災厄」時用含加成的目前災厄，卡面寫「原始災厄」才看卡面；相同效果可疊加；《誘蛾林道》一次襲擊只觸發一次；《狂亂質詢》等同時機效果由回合玩家先結算；《催眠師》可拿回自己。
- 選項「沒有可控訴的卡時自動跳過」（預設開）：關閉時一律詢問。
- 罪惡信徒：只提供符號；不提供星塵、不能襲擊、被動效果失效。
- 「你擁有(N*符號)」= 你場上所有牌的符號（含教主、儀式、罪惡信徒）。
- 星塵以打出魔法時計算；沒有「可」字的星塵效果強制執行。
